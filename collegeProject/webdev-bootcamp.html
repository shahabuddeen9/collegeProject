1️⃣ What is HTML?

Beginner

Understanding HTML

HTML stands for HyperText Markup Language. It's the foundation of web pages—like the skeleton of a website.

Think of a website like a car:
🏗️ HTML = Framework (structure)
🎨 CSS = Paint & design (looks)
⚙️ JavaScript = Engine & buttons (interactivity)

What Does HTML Do?

  • Creates the structure of web pages
  • Uses tags to tell the browser what things are
  • Organizes content (headings, paragraphs, lists, etc.)
  • Makes content accessible to all devices and screen readers

HTML Tags - The Building Blocks

HTML documents are made of tags. A tag is wrapped in angle brackets:

<tagname>content</tagname>
💡 Key Concept: HTML tags usually come in pairs:
- Opening tag: <p>
- Closing tag: </p>
- Some tags are self-closing: <img />, <br />

Your First HTML Page

Here's the minimum HTML needed for a web page:

<!DOCTYPE html> <html> <head> <title>My First Page</title> </head> <body> <h1>Hello, World!</h1> </body> </html>

What Each Part Means:

  • <!DOCTYPE html> - Tells the browser this is HTML5
  • <html> - Root element, wraps everything
  • <head> - Hidden info (title, metadata, links to CSS)
  • <body> - Visible content users see
  • <title> - Text shown in browser tab

2️⃣ HTML Page Structure

Beginner

The Complete HTML Template

Every professional HTML page should follow this structure:

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <meta name="viewport" content="width=device-width, initial-scale=1.0"> <title>Page Title</title> <link rel="stylesheet" href="styles.css"> </head> <body> <header> <h1>My Website</h1> </header> <main> <article> <h2>Article Title</h2> <p>Article content...</p> </article> </main> <footer> <p>© 2026 My Website</p> </footer> <script src="script.js"></script> </body> </html>

Breaking Down the Head Section

  • <meta charset="UTF-8"> - Character encoding (supports all languages)
  • <meta name="viewport"...> - IMPORTANT: Makes site mobile-friendly
  • <title> - Appears in browser tab and search results
  • <link rel="stylesheet"> - Links to CSS file

Body Structure Best Practices

  • <header> - Top section (logo, nav, title)
  • <nav> - Navigation menu
  • <main> - Primary content
  • <article> - Self-contained content
  • <section> - Thematic grouping of content
  • <aside> - Sidebar content
  • <footer> - Page footer (copyright, links)
⚠️ Don't Forget! Always put your <script> tag at the bottom of the body, not in the head. This makes pages load faster!

4️⃣ Attributes & Links

Beginner

What Are Attributes?

Attributes provide additional information about HTML elements. They go inside the opening tag:

<tag attribute="value">content</tag>

Common Attributes

<!-- ID: Unique identifier --> <div id="header"></div> <!-- CLASS: For styling (can use multiple) --> <div class="container main"></div> <!-- STYLE: Inline CSS --> <p style="color: red; font-size: 20px;">Red text</p> <!-- DATA: Store custom information --> <div data-user-id="123"></div> <!-- TITLE: Tooltip on hover --> <p title="This is a tooltip">Hover over me</p> <!-- ARIA: Accessibility --> <button aria-label="Close menu">✕</button>

Links - The Most Important!

<!-- Basic link --> <a href="page.html">Click here</a> <!-- Open in new tab --> <a href="page.html" target="_blank">Open in new tab</a> <!-- External website --> <a href="https://google.com">Go to Google</a> <!-- Email link --> <a href="mailto:hello@example.com">Email me</a> <!-- Jump to section (anchor) --> <a href="#section2">Go to Section 2</a> ... <h2 id="section2">Section 2</h2>

Image Attributes

<img src="photo.jpg" <!-- Path to image (REQUIRED) --> alt="My photo" <!-- Alternative text (REQUIRED) --> width="300" <!-- Width in pixels --> height="200" <!-- Height in pixels --> title="Hover text" <!-- Tooltip --> &g
🎯 ID vs CLASS:
- ID = unique identifier (use once per page)
- CLASS = reusable style (use many times)

5️⃣ Forms & Input Elements

Beginner

Why Forms Matter

Forms are how users send data to your website. Think of them like digital questionnaires:

  • Login forms (username, password)
  • Contact forms (name, email, message)
  • Sign up forms (registration info)
  • Search boxes

Basic Form Structure

<form action="/submit" method="POST"> <label for="name">Name:</label> <input type="text" id="name" name="name" required> <button type="submit">Submit</button> </form>

Input Types

<!-- TEXT INPUT --> <input type="text" placeholder="Enter your name"> <!-- EMAIL --> <input type="email" placeholder="your@email.com"> <!-- PASSWORD --> <input type="password" placeholder="Enter password"> <!-- NUMBER --> <input type="number" min="1" max="100"> <!-- CHECKBOX --> <input type="checkbox"> I agree to terms <!-- RADIO BUTTON --> <input type="radio" name="gender"> Male <input type="radio" name="gender"> Female <!-- DROPDOWN --> <select name="country"> <option>Select country</option> <option value="usa">USA</option> <option value="uk">UK</option> </select> <!-- TEXT AREA (multi-line) --> <textarea rows="5" cols="40"></textarea> <!-- DATE --> <input type="date"> <!-- BUTTONS --> <button type="submit">Send</button> <button type="reset">Clear</button>
💡 Form Attributes:
- name = identifies the field when submitting
- required = user must fill it before submitting
- placeholder = hint text
- for = label connects to input by ID

6️⃣ Semantic HTML

Intermediate

What is Semantic HTML?

Semantic HTML uses tags that describe meaning, not just appearance. This is better for:

  • Accessibility: Screen readers understand content better
  • SEO: Search engines rank semantic sites higher
  • Readability: Code is easier to understand

Semantic vs Non-Semantic

<!-- ❌ NON-SEMANTIC (just generic containers) --> <div class="header"></div> <div class="nav"></div> <div class="main"></div> <div class="footer"></div> <!-- ✅ SEMANTIC (meaning is clear) --> <header></header> <nav></nav> <main></main> <footer></footer>

Semantic HTML Tags

  • <header> - Top section with title/logo
  • <nav> - Navigation menu
  • <main> - Primary content
  • <article> - Self-contained content (blog post, news)
  • <section> - Thematic grouping
  • <aside> - Sidebar content
  • <footer> - Bottom section
  • <figure> + <figcaption> - Image with caption
  • <time> - Human/machine readable date/time
  • <address> - Contact information

Complete Semantic Page Layout

<!DOCTYPE html> <html lang="en"> <head> <title>My Blog</title> </head> <body> <header> <h1>My Blog</h1> </header> <nav> <a href="/">Home</a> <a href="/about">About</a> </nav> <main> <article> <h2>Article Title</h2> <time datetime="2026-02-21">February 21, 2026</time> <p>Article content...</p> </article> <aside> <h3>Related Posts</h3> <ul> <li><a href="#">Post 1</a></li> <li><a href="#">Post 2</a></li> </ul> </aside> </main> <footer> <p>© 2026 My Blog</p> </footer> </body> </html>

7️⃣ What is CSS?

Beginner

CSS Makes Things Look Good

CSS stands for Cascading Style Sheets. While HTML creates structure, CSS controls the appearance: colors, fonts, layouts, animations.

HTML is like the blueprint of a house
CSS is like the interior design (colors, furniture placement, decorations)

Three Ways to Use CSS

1️⃣ Inline CSS (Not recommended)

<p style="color: red; font-size: 20px;">Red text</p>

2️⃣ Internal CSS (Good for learning)

<head> <style> p { color: red; font-size: 20px; } </style> </head>

3️⃣ External CSS (Best practice)

<!-- In HTML file --> <head> <link rel="stylesheet" href="styles.css"> </head> /* In styles.css */ p { color: red; font-size: 20px; }

Basic CSS Syntax

/* COMMENT */ selector { property: value; property: value; }

Example

h1 { color: blue; /* Text color */ font-size: 32px; /* Text size */ text-align: center; /* Center alignment */ margin: 20px; /* Space around element */ }

8️⃣ CSS Selectors

Beginner

What Are Selectors?

Selectors target which HTML elements to style. There are many ways to select elements:

1. Element Selector

p { color: blue; /* ALL paragraphs are blue */ }

2. Class Selector

/* CSS */ .highlight { background-color: yellow; } <!-- HTML --> <p class="highlight">This is highlighted</p>

3. ID Selector

/* CSS */ #header { background-color: navy; color: white; } <!-- HTML --> <div id="header"></div>

4. Attribute Selector

input[type="text"] { border: 1px solid gray; } img[alt="profile"] { width: 100px; }

5. Combinators (Combining Selectors)

/* Child selector */ div > p { color: red; /* p directly inside div */ } /* Descendant selector */ div p { color: blue; /* p anywhere inside div */ } /* Adjacent sibling */ h1 + p { font-size: 18px; /* p right after h1 */ } /* Multiple classes */ .button.primary { background: blue; }

6. Pseudo-classes

a:hover { color: red; /* When mouse hovers */ } button:active { transform: scale(0.95); /* When clicked */ } input:focus { border-color: blue; /* When selected */ } p:first-child { font-weight: bold; /* First p element */ }
Selector Specificity (Priority):
1. ID (#id) = highest
2. Class (.class) = medium
3. Element (p) = lowest
This determines which style wins if two conflict!

9️⃣ Colors & Fonts

Beginner

Color Formats

/* Named colors */ p { color: red; } p { color: blue; } /* HEX (hexadecimal) */ p { color: #FF0000; } /* Red */ p { color: #00FF00; } /* Green */ p { color: #0000FF; } /* Blue */ /* RGB (Red, Green, Blue) */ p { color: rgb(255, 0, 0); } /* Red */ p { color: rgb(100, 100, 100); } /* Gray */ /* RGBA (RGB + Transparency) */ p { color: rgba(255, 0, 0, 0.5); } /* 50% transparent red */ /* HSL (Hue, Saturation, Lightness) */ p { color: hsl(0, 100%, 50%); } /* Red */

Font Basics

p { font-family: Arial, sans-serif; /* Font name */ font-size: 16px; /* Text size */ font-weight: bold; /* bold, normal, 700 */ font-style: italic; /* italic, normal */ line-height: 1.6; /* Space between lines */ letter-spacing: 2px; /* Space between letters */ text-transform: uppercase; /* uppercase, lowercase, capitalize */ }

Font Categories

  • Serif: Times New Roman, Georgia (fancy, formal)
  • Sans-serif: Arial, Helvetica, Verdana (clean, modern)
  • Monospace: Courier, monospace (like typewriter)

Google Fonts (Free Professional Fonts)

<!-- Add to <head> --> <link href="https://fonts.googleapis.com/css2?family=Roboto:wght@400;700&display=swap" rel="stylesheet"> <!-- Use in CSS --> p { font-family: 'Roboto', sans-serif; }

Text Properties

p { text-align: center; /* left, center, right, justify */ text-decoration: underline; /* underline, overline, line-through */ text-shadow: 2px 2px 4px gray; /* Drop shadow effect */ word-spacing: 10px; /* Space between words */ background-color: yellow; /* Background color */ }

🔟 CSS Box Model

Intermediate

Every Element is a Box

The CSS Box Model is crucial to understand. Every HTML element has 4 layers:

Outside to Inside:
📦 Margin (space outside)
🎁 Border (line around box)
📝 Padding (space inside, before content)
✏️ Content (actual text/images)

Visual Representation

     ┌── Margin ──────────────────┐
     │ ┌── Border ─────────────┐  │
     │ │ ┌── Padding ────────┐ │  │
     │ │ │                   │ │  │
     │ │ │     CONTENT      │ │  │
     │ │ │                   │ │  │
     │ │ └── Padding ────────┘ │  │
     │ └── Border ─────────────┘  │
     └── Margin ──────────────────┘

The Box Model Properties

div { /* CONTENT SIZE */ width: 300px; height: 200px; /* PADDING (inside) */ padding: 20px; /* All sides */ padding: 10px 20px; /* top+bottom, left+right */ padding: 10px 20px 15px 5px;/* top, right, bottom, left */ /* BORDER (line) */ border: 2px solid black; border-radius: 8px; /* Rounded corners */ /* MARGIN (outside) */ margin: 20px; /* All sides */ margin: 0 auto; /* Center horizontally */ }

Border Styles

border: 2px solid black; /* solid line */ border: 2px dashed red; /* dashed line */ border: 2px dotted blue; /* dotted line */ border: 2px double purple; /* double line */ /* Individual sides */ border-top: 2px solid black; border-right: 2px solid blue; border-bottom: 2px solid red; border-left: 2px solid green;

Box Sizing

/* Default behavior */ div { width: 300px; padding: 20px; border: 2px solid black; /* Total width = 300 + 20 + 20 + 2 + 2 = 344px */ } /* Better approach (includes padding/border in width) */ * { box-sizing: border-box; } div { width: 300px; padding: 20px; border: 2px solid black; /* Total width = 300px (padding/border included) */ }
💡 Pro Tip: Use box-sizing: border-box; on all elements! This makes sizing much more intuitive.

1️⃣1️⃣ Flexbox Layout

Intermediate

What is Flexbox?

Flexbox is a modern CSS tool for creating flexible, responsive layouts. It's much easier than old methods!

Container Properties

.container { display: flex; /* ACTIVATE FLEXBOX */ flex-direction: row; /* row, column, row-reverse, column-reverse */ justify-content: center; /* Align items horizontally */ /* Options: flex-start, center, flex-end, space-between, space-around */ align-items: center; /* Align items vertically */ /* Options: flex-start, center, flex-end, stretch */ gap: 20px; /* Space between items */ flex-wrap: wrap; /* Wrap items if too small */ }

Item Properties

.item { flex: 1; /* Take equal space */ flex: 2; /* Take 2x space */ flex-basis: 200px; /* Minimum size */ align-self: center; /* Override container alignment */ }

Common Layouts

Horizontal Center

.container { display: flex; justify-content: center; align-items: center; height: 200px; }

Space Between

.container { display: flex; justify-content: space-between; }

Responsive Columns

.container { display: flex; gap: 20px; flex-wrap: wrap; } .item { flex: 1; min-width: 250px; }

1️⃣2️⃣ CSS Grid

Intermediate

Grid Basics

CSS Grid is perfect for 2D layouts (rows AND columns). Flexbox is better for 1D layouts.

.container { display: grid; grid-template-columns: 1fr 1fr 1fr; /* 3 equal columns */ grid-template-rows: 100px 200px; /* Row heights */ gap: 20px; /* Space between items */ } /* Responsive columns */ .container { display: grid; grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); gap: 20px; }

1️⃣3️⃣ Responsive Design

Intermediate

Mobile-First Design

Responsive design means your site looks good on all devices:

/* Mobile first (small screens) */ .container { width: 100%; font-size: 14px; } /* Tablet screens */ @media (min-width: 768px) { .container { width: 750px; font-size: 16px; } } /* Desktop screens */ @media (min-width: 1024px) { .container { width: 1000px; font-size: 18px; } }

1️⃣5️⃣ Variables & Data Types

Beginner

Variables Are Containers

Variables store information that your program uses:

/* CREATE A VARIABLE */ let name = "John"; /* Store text */ let age = 25; /* Store number */ let isStudent = true; /* Store true/false */ /* USE THE VARIABLE */ console.log(name); /* Output: John */ console.log(age + 5); /* Output: 30 */ /* CHANGE THE VALUE */ name = "Jane"; age = 26;

let vs const vs var

let name = "John"; /* Can change, block scope */ const age = 25; /* Cannot change (BEST) */ var city = "NYC"; /* Old way, avoid it */

Data Types

/* STRING (text) */ let text = "Hello"; let quote = 'Single quotes work too'; let template = `This is ${name}`; /* Template literal */ /* NUMBER (int or float) */ let count = 42; let price = 19.99; /* BOOLEAN (true/false) */ let isActive = true; let isEmpty = false; /* ARRAY (list) */ let fruits = ["apple", "banana", "orange"]; console.log(fruits[0]); /* Output: apple */ /* OBJECT (key-value pairs) */ let person = { name: "John", age: 25, city: "NYC" }; console.log(person.name); /* Output: John */ /* NULL and UNDEFINED */ let empty = null; /* Explicitly empty */ let noDefined; /* Not assigned yet */

1️⃣6️⃣ Operators

Beginner

Arithmetic Operators

let a = 10; let b = 3; console.log(a + b); /* 13 (addition) */ console.log(a - b); /* 7 (subtraction) */ console.log(a * b); /* 30 (multiplication) */ console.log(a / b); /* 3.333... (division) */ console.log(a % b); /* 1 (remainder) */ console.log(a ** 2); /* 100 (exponent) */

Comparison Operators

console.log(5 == "5"); /* true (loose equal) */ console.log(5 === "5"); /* false (strict equal) */ console.log(5 != 6); /* true */ console.log(5 !== "5"); /* true */ console.log(10 > 5); /* true */ console.log(10 < 5); /* false */ console.log(10 >= 10); /* true */ console.log(10 <= 5); /* false */

Logical Operators

console.log(true && true); /* true (AND) */ console.log(true && false); /* false */ console.log(true || false); /* true (OR) */ console.log(!true); /* false (NOT) */

Assignment Operators

let x = 10; x += 5; /* x = x + 5 → 15 */ x -= 3; /* x = x - 3 → 12 */ x *= 2; /* x = x * 2 → 24 */ x /= 4; /* x = x / 4 → 6 */ x++; /* x = x + 1 → 7 */ x--; /* x = x - 1 → 6 */

1️⃣7️⃣ Functions

Beginner

Functions Are Reusable Code

Functions let you write code once and use it many times:

/* DECLARE FUNCTION */ function greet(name) { console.log("Hello, " + name + "!"); } /* USE FUNCTION */ greet("John"); /* Output: Hello, John! */ greet("Jane"); /* Output: Hello, Jane! */

Return Values

function add(a, b) { return a + b; /* Send back result */ } let result = add(5, 3); console.log(result); /* Output: 8 */

Arrow Functions (Modern)

/* Traditional function */ function multiply(a, b) { return a * b; } /* Arrow function (same thing, shorter) */ const multiply = (a, b) => { return a * b; }; /* Super short */ const multiply = (a, b) => a * b;

Common Function Patterns

/* No parameters */ function sayHi() { console.log("Hi!"); } /* Multiple parameters */ function create Profile(name, age, email) { console.log(name, age, email); } /* Default parameters */ function greet(name = "Friend") { console.log("Hello, " + name); } greet(); /* Output: Hello, Friend */ greet("John"); /* Output: Hello, John */

1️⃣8️⃣ Control Flow (if/else/loops)

Beginner

IF Statements

let age = 18; if (age >= 18) { console.log("You are an adult"); } else { console.log("You are a minor"); } /* Multiple conditions */ if (age < 13) { console.log("Child"); } else if (age < 18) { console.log("Teenager"); } else { console.log("Adult"); }

FOR Loops

/* Count from 1 to 5 */ for (let i = 1; i <= 5; i++) { console.log(i); } /* Loop through array */ let fruits = ["apple", "banana", "orange"]; for (let i = 0; i < fruits.length; i++) { console.log(fruits[i]); }

WHILE Loops

let count = 1; while (count <= 5) { console.log(count); count++; }

Switch Statement

let day = "Monday"; switch(day) { case "Monday": console.log("Start of week"); break; case "Friday": console.log("Almost weekend!"); break; default: console.log("Regular day"); }

1️⃣9️⃣ DOM Manipulation

Intermediate

What is the DOM?

The DOM (Document Object Model) is how JavaScript interacts with HTML. It lets you:

  • Select and change HTML elements
  • Show/hide elements
  • Change text and attributes
  • Respond to user actions

Selecting Elements

/* By ID */ let header = document.getElementById("header"); /* By class */ let items = document.getElementsByClassName("item"); /* By tag */ let paragraphs = document.getElementsByTagName("p"); /* MODERN WAY (preferred) */ let element = document.querySelector("#header"); /* First match */ let elements = document.querySelectorAll(".item"); /* All matches */

Changing Content

let heading = document.querySelector("h1"); /* Change text */ heading.textContent = "New Title"; /* Change HTML */ heading.innerHTML = "<span>New Title</span>"; /* Get current text */ console.log(heading.textContent);

Changing Styles

let box = document.querySelector(".box"); box.style.backgroundColor = "blue"; box.style.fontSize = "20px"; box.style.display = "none"; /* Hide element */ box.style.display = "block"; /* Show element */

Adding/Removing Classes

let button = document.querySelector("button"); button.classList.add("active"); /* Add class */ button.classList.remove("active"); /* Remove class */ button.classList.toggle("active"); /* Toggle on/off */ button.classList.contains("active"); /* Check if has class */

Creating Elements

/* Create new element */ let newParagraph = document.createElement("p"); newParagraph.textContent = "Hello!"; /* Add to page */ document.body.appendChild(newParagraph);

2️⃣0️⃣ Events & Interactivity

Intermediate

Events Are User Actions

Events happen when users interact with your page:

  • click (mouse click)
  • mouseover (hover)
  • keydown (key press)
  • submit (form submission)
  • load (page loaded)

Adding Event Listeners

/* HTML */ <button id="myButton">Click me</button> /* JavaScript */ let button = document.getElementById("myButton"); button.addEventListener("click", function() { console.log("Button clicked!"); }); /* With arrow function */ button.addEventListener("click", () => { console.log("Button clicked!"); });

Accessing Event Information

let input = document.querySelector("input"); input.addEventListener("keydown", (event) => { console.log("Key pressed:", event.key); console.log("Key code:", event.keyCode); }); button.addEventListener("click", (event) => { console.log("Clicked at:", event.clientX, event.clientY); });

Preventing Default Behavior

let form = document.querySelector("form"); form.addEventListener("submit", (event) => { event.preventDefault(); /* Stop form submission */ console.log("Form prevented from submitting"); });
